## Problem: Valid Anagram (Easy)

Link: https://leetcode.com/problems/valid-anagram/

### Approach

I used a frequency array to count the characters in both strings.
If the frequency of every character is the same, the strings are anagrams.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The strings are anagrams when they contain the same characters with the same frequency.
